How to customize the Wildlands HUD

Select a whole category or individual items. Checked means hide; unchecked means keep. Apply with the game closed after making your choices. These are the 14 options in installer 0.7.0; its checkbox labels are in Portuguese.

The configurable edition is experimental and still needs visual gameplay confirmation. File and installer tests do not verify every HUD state. Each answer describes the option’s scope, without promising compatibility with every game version.

How do I hide enemy distance markers in Wildlands?

Under Characters and equipment, check “Inimigos: ícones, nomes, distâncias e pulsos” and apply with the game closed. This option groups enemy distances in meters, names, icons, marking circles and pulses. There is no separate distance-only switch that retains the other enemy indicators.

How do I remove generator and enemy equipment markers?

Check “Objetos: geradores, alarmes, minas e afins” to hide icons, names and distances handled by the shared object marker, including generators and enemy equipment. This also affects player mines and other objects in that group; generators cannot be selected separately. The equipment remains in the world and keeps its functions.

Can I hide teammate markers but keep downed allies visible?

Check “Aliados normais: ícones, nomes e distâncias”. The downed-ally symbol/gauge and conditional off-screen arrows are retained. Ally names and distances are hidden even when an ally is downed. The downed indicator is protected and has no removal checkbox.

Can I keep pings and manual waypoints visible?

Yes. Leave “Pings e pontos manuais” unchecked, as it is by default. These markers can remain while enemies and objectives are hidden. Check it under World markers to hide pings and manual waypoints too. This controls their display, not the ability to create a point.

How do I hide mission, objective and activity markers?

Check “Objetivos e atividades” under World markers. It hides the group’s in-world indicators without completing, deleting or changing missions. It is checked by default and independent of pings; it does not remove the full map or mission menu.

How do I hide collectible, resource and reward markers?

Check “Coleta e recompensas” to hide the collectible, resource and reward markers covered by this group. The items remain in the game. It is checked by default and can be unchecked without restoring every other marker.

How do I hide location and radio signal indicators?

Check “Locais e sinais de rádio” to hide those in-world markers. It is checked by default. It changes this group’s visual indicators, not radio audio or the locations themselves.

How do I hide sync shot markers?

Check “Tiro sincronizado” to hide visual sync shot markers. It is checked by default. This does not disable the sync shot mechanic or change companion behavior.

Can I hide world warnings and capture point markers?

Yes. “Alertas no cenário e pontos de captura” controls this group’s visual markers and is checked by default. It does not remove every game notification: interaction prompts such as “press X” remain protected.

How do I hide drone enemy locating indicators?

Under Drone and binoculars, check “Ajuda visual de localização / identificação”. It controls visual scanning, identification indicators and circles shared by the drone and binoculars, and is checked by default. Keep Enemies checked to hide the markers over enemies as well. The mod does not prevent automatic game tagging or change enemy intelligence.

How do I keep binocular and drone information?

Leave “Informações de uso do binóculo e drone” unchecked. This default can be combined with hidden visual locating assistance. Check it only if you also want to hide the equipment’s operational interface. Drone and binoculars share resources, so there are no separate operational switches; interaction prompts remain protected.

How do I hide the minimap without removing the rest of the HUD?

Under Operational interface, check “Minimapa” and leave the other information you want unchecked. The minimap is visible by default. This does not remove the menu map or modify the game terrain.

How do I remove the crosshair in Ghost Recon Wildlands?

Check “Mira” under Operational interface to hide the crosshair elements covered by the mod. Leave it unchecked to retain them, as in the defaults. It controls HUD elements, not accuracy, recoil, damage or weapon behavior.

How do I hide weapon and ammunition information?

Check “Informações de armas e munição” to hide this interface group. It is unchecked by default, retaining the information. Hiding the counter does not grant unlimited ammunition or change the available amount.

Installation steps · Restore the original HUD

02 / Get into the game

Download.
Choose. Apply.

One offline installer with checkboxes and a way to restore your original files.

Before you start
Windows 64-bit · Ghost Recon Wildlands installed
9 GB of free disk space recommended
Administrator access · Game closed

Get WildlandsHUD.zip ↓

  1. Download and extract

    Get the v0.7.0 release and extract the ZIP to a folder. Python is not required.

  2. Close the game and open the installer

    Right-click WildlandsHUD.exe and choose Run as administrator. The installer interface is in Portuguese.

  3. Select your game folder and options

    Click Escolher… (Choose) to select the game installation folder. Check the categories you want to hide.

  4. Apply the mod

    Click Aplicar mod (Apply mod), wait for completion, then launch the game.

Want the original HUD back? Close the game, select the same game folder in the installer, and click Restaurar originais (Restore originals). About backups.

How do I update the mod or change my choices?

Close the game, open the current installer, select the same folder, adjust the checkboxes and click Aplicar mod. The app looks for the previous installation record automatically. If requested, use “Já uso o mod: selecionar registro anterior…” to select the previous manifest.json. “Voltar à seleção padrão” resets the checkboxes only; apply to change the game.

How can I help the project and follow updates?

Follow releases on GitHub, share this guide and report issues with the mod version and selected checkboxes. Reports of what worked in gameplay also help document each option’s limits.

Which game versions are compatible?

The installer checks game files against supported hashes and refuses unknown versions. A different game update or another mod may change those files. Compatibility with every edition or update is not guaranteed; check the v0.7.0 release notes for the release details.

How do backups and restoration work?

Original copies are saved beside the patched files with the .phoenixhud.original suffix. Local patch records are kept in %LOCALAPPDATA%\WildlandsHUD. Keep the backups: the Restaurar originais button uses them to restore the original files. Close the game and select the same installation folder before restoring.

Are downed allies still indicated?

Yes. The symbol/gauge and conditional off-screen arrows remain. Hiding normal allies also hides downed ally names/distances.

Does it remove the minimap or the whole HUD?

You can hide the minimap, crosshair and weapon information independently, but they remain visible by default. Defaults hide enemies, equipment, normal allies, objectives and visual locating assistance; pings, operational drone/binocular information, interaction and downed allies remain. This is not a switch to remove every part of the game interface.

Can I use it in multiplayer?

This project makes no claim of multiplayer safety or anti-cheat compatibility. It does not provide an anti-cheat bypass. An “offline installer” means installation does not require an online service; it is not a statement about supported game modes.

01 / Choose your view

Two ways to clear the field.

Choose a mode in the installer. V3 hides enemy markers; V4 also hides normal ally markers. Both worked in the creator’s reported gameplay tests.

ONE DOWNLOAD
TWO MODES · ORIGINAL BACKUPS

V3

CONFIRMED IN GAME

Clear the enemy overlay.

A focused option that removes the floating visual cues above enemies.

  • Removes 3D enemy icons.
  • Removes enemy meters and circular pulses.
  • Leaves ally HUD elements as they are.

The creator has verified the V3 enemy marker changes during gameplay.

V4

CONFIRMED IN GAME

Give your squad more space.

Adds ally HUD changes to V3’s enemy cleanup for an even lighter overlay.

  • Hides normal ally icons, names, and distances.
  • Designed to keep the downed-ally symbol and gauge, plus the conditional off-screen arrow.
  • Hides ally names and distances even when an ally is downed.

The creator reported a successful V4 gameplay test. This does not guarantee the same result in every installation or game state.

FOCUSED SCOPEThis mod targets the 3D HUD. It does not aim to remove the entire HUD, minimap, or sync shot interface.

Before you start

Get WildlandsHUD.zip ↓

  1. Download and extract

    Get the v0.4.0 release and extract the ZIP to a folder. Python is not required.

  2. Close the game and open the installer

    Right-click WildlandsHUD.exe and choose Run as administrator. The installer interface is in Portuguese.

  3. Select your game folder and mode

    Click Escolher… (Choose) to select the game installation folder. Choose V3 or the V4 option from the mode dropdown.

  4. Apply the mod

    Click Aplicar mod (Apply mod), wait for completion, then launch the game.

Want the original HUD back? Close the game, select the same game folder in the installer, and click Restaurar originais (Restore originals). About backups.

03 / Field notes

A few things
to know.

Compatibility, backups, and what this release actually changes.

Report an issue on GitHub ↗
Which game versions are compatible?

The installer checks game files against supported hashes and refuses unknown versions. A different game update or another mod may change those files. Compatibility with every edition or update is not guaranteed; check the v0.4.0 release notes for the release details.

How do backups and restoration work?

Original copies are saved beside the patched files with the .phoenixhud.original suffix. Local patch records are kept in %LOCALAPPDATA%\WildlandsHUD. Keep the backups: the Restaurar originais button uses them to restore the original files. Close the game and select the same installation folder before restoring.

What does V4 keep for downed allies?

V4 is designed to preserve the downed-ally symbol and gauge, along with the conditional off-screen arrow. Ally names and distance text are hidden even when downed. The creator reported that V4 was tested and worked. The report does not cover every possible game state or installation.

Does it remove the minimap or the whole HUD?

No. Wildlands HUD focuses on 3D enemy markers and, in V4, selected ally markers. The global HUD, minimap, and sync shot interface are outside this mod’s scope.

Can I use it in multiplayer?

This project makes no claim of multiplayer safety or anti-cheat compatibility. It does not provide an anti-cheat bypass. An “offline installer” means installation does not require an online service; it is not a statement about supported game modes.
